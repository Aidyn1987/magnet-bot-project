# Проект «Магнит» 🧲
ИИ-ассистент для класса: рейтинг, мотивация и интеграция с школьными платформами.
Разработан командой «Магнит» для хакатона «Идея Фикс» (направление «Портал в будущее»).

## О проекте
«Магнит» — это чат-бот в мессенджере MAX, который помогает ученикам отслеживать свой прогресс, получать персональные мотивационные сообщения и видеть рейтинг класса. 

## Как запустить проект через Docker
Для запуска вам понадобится установленный [Docker](https://www.docker.com/).

1. Клонируйте репозиторий:
   `git clone https://github.com/Aidyn1987/magnet-bot.git`
2. Перейдите в папку проекта:
   `cd magnet-bot`
3. Создайте файл `.env` в корне проекта и добавьте в него токен вашего бота MAX:
   `MAX_BOT_TOKEN=ваш_токен_здесь`
4. Соберите Docker-образ:
   `docker build -t magnet-bot .`
5. Запустите контейнер:
   `docker run --env-file .env magnet-bot`

## Пример запуска через командную строку
После успешного запуска контейнера бот готов к работе. Откройте мессенджер MAX, найдите своего бота и отправьте команду `/start`.

## Технологии
- Python 3.13
- Библиотека `maxapi` для работы с мессенджером MAX
- `python-dotenv` для безопасного хранения токенов
